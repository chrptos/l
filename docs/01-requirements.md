# 1. 要件定義

## 1.1 目的

誰でも講師としてオンライン講座を作って販売でき、受講者は自分のペースで学べる場を提供する。
プラットフォームは販売手数料で収益を得る。

## 1.2 スコープ

| 対象 | 対象外（当面） |
| --- | --- |
| Web（PC・スマホのブラウザ） | ネイティブアプリ、オフライン再生 |
| 日本語・日本円 | 多言語・多通貨 |
| 個人向け（B2C） | 法人研修（B2B）・組織ライセンス・SSO |
| 録画済み動画コース | ライブ配信・ウェビナー |

## 1.3 アクター

| アクター | 説明 |
| --- | --- |
| ゲスト | 未ログイン。コースの閲覧・検索・無料プレビュー視聴ができる |
| 受講者 | 登録ユーザー。購入・受講・レビュー・質問ができる |
| 講師 | 受講者が講師登録したもの（1ユーザーが両方の役割を持つ）。コースを作って販売する |
| 管理者 | 運営。コース審査・通報対応・返金・ユーザー管理・売上管理を行う |
| 外部システム | Stripe（決済・送金）、動画配信サービス、メール配信 |

## 1.5 主要な業務ルール

| ルール | 内容（案） | 備考 |
| --- | --- | --- |
| 手数料 | 販売額（税抜）の **30%** をプラットフォーム、**70%** を講師に分配。設定で変更可 | [Q3](#17-未決事項) |
| 価格 | 無料、または ¥500〜¥50,000 の範囲で100円単位。税込表示 | 景品表示法・総額表示 |
| 返金 | 購入から30日以内、かつ視聴がコースの30%未満なら申請で自動返金。それ以外は管理者判断 | [Q4](#17-未決事項) |
| 支払い | 毎月末で締め、**返金期間（30日）を過ぎた売上**のみ確定し、翌月15日に Stripe で送金 | 返金による講師残高のマイナスを防ぐ |
| 最低支払額 | 確定残高が ¥1,000 未満なら翌月に繰り越す | 振込コスト対策 |
| 公開審査 | 初回公開時と、価格・タイトル以外の大きな変更時に審査する | 最低5レクチャー、合計30分以上の動画 |
| 非公開化 | 受講者がいるコースは削除不可。非公開にしても購入済みの受講者は引き続き視聴できる | 受講者の権利保護 |
| アクセス期間 | 購入したコースは無期限に視聴可能。返金されると視聴不可 | |

## 1.6 非機能要件

規模の想定: 登録ユーザー〜1万、同時視聴〜200、コース〜500、動画の合計〜2,000時間。

| 分類 | 要件 |
| --- | --- |
| **性能** | ページ表示の p95 < 1.5秒（動画を除く）。検索の p95 < 500ms。動画の再生開始 < 3秒 |
| **可用性** | 月間 99.5%（マネージドサービスの SLA に準じる）。決済・Webhook は**冪等**かつ再試行可能にする |
| **拡張性** | 10倍（ユーザー10万人）まで**大きな再設計なし**で耐えられること（DB のスケールアップ・キャッシュ追加の範囲で） |
| **セキュリティ** | OWASP Top 10 に対策。認可はすべてサーバー側でチェック。動画は署名付き URL（有効期限つき）。カード情報は保持しない（Stripe に任せ、PCI DSS SAQ A の範囲） |
| **プライバシー** | 個人情報保護法に準拠。プライバシーポリシーを公開。個人データの削除要求に対応 |
| **データ保全** | DB はポイントインタイムリカバリ（7日以上）。会計データ（注文・台帳）は論理削除のみ、7年間保持 |
| **監視** | エラー追跡、外形監視、Webhook 失敗のアラート |
| **アクセシビリティ** | WCAG 2.1 AA を目標（キーボード操作、字幕、コントラスト） |
| **法令** | 特定商取引法に基づく表記、利用規約（受講者・講師）、資金決済法の確認（[Q1](#17-未決事項)） |
| **運用コスト** | 初期は固定費を低く抑え、従量課金中心にする |
| **開発体制** | 少人数（1〜3名）で保守できる構成。インフラ運用の作業を最小にする |

## 1.7 未決事項

設計確定の前に、事業側で決める必要があるもの。

| # | 論点 | 選択肢 / 論点 | 影響範囲 |
| --- | --- | --- | --- |
| Q1 | **販売主体** | (a) プラットフォームが販売者になり講師へ報酬を払う / (b) 講師が販売者でプラットフォームは代理受領 | 決済方式・領収書・税務・資金決済法。**専門家（税理士・弁護士）への確認を推奨** |
| Q2 | インボイス制度への対応 | 誰の登録番号で適格請求書を出すか。講師が免税事業者の場合の扱い | 領収書の発行、講師登録時の入力項目 |
| Q3 | 手数料率 | 一律30%か、集客経路によって変えるか（講師が自分で集客した場合は手数料を下げる等） | 台帳設計、紹介リンクのトラッキング |
| Q4 | 返金ポリシー | 期間・視聴率の条件、手動承認の有無 | 返金フロー、支払い確定のタイミング |
| Q5 | 講師の本人確認 | Stripe の KYC だけで足りるか、追加の審査が必要か | 講師オンボーディング |
| Q6 | 対象年齢 | 未成年の購入を認めるか | 利用規約、決済 |

> 本設計では **Q1 = (a) プラットフォームが販売者** を仮定する（Udemy と同じ形で、決済・返金・顧客対応を一元化しやすいため）。
