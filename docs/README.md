## 設計の前提（2026-11 時点の合意）

- **事業モデル**: 誰でも講師になれる講師マーケットプレイス（Udemy 型）。講師への収益分配あり。
- **規模**: 初期〜1年後で受講者数千人規模。**シンプルさ・運用コスト最小**を最優先し、拡張余地は残す。
- **既存資産**: `src/` の MVP（Next.js + SQLite）は動くプロトタイプ。画面と業務フローは流用し、基盤（DB・決済・動画）を置き換える。
